# 员工花名册 · 智能统计系统

基于 **Python + PySide6**、采用**纯正 iOS Liquid Glass 毛玻璃风格**的桌面软件。窗口顶部使用 **macOS 风格交通灯按钮**（红关闭 / 黄最小化 / 绿全屏）。录入或导入员工信息后，自动统计性别、工龄、年龄、干部、部门人数等指标，提供**劳动合同到期提醒**，并支持**已离职员工管理**。

## 功能

### 1. 员工花名册管理
- 添加、编辑（双击行）、删除员工
- **多字段搜索**：姓名 / 部门 / 职位 / 电话 / 邮箱 / 学历
- **部门分类筛选**：按部门查看员工，实时显示"当前显示 N / 总数 人"

### 2. 文件导入（新）
- 支持格式：**xlsx / xls / csv / pdf / pptx / ppt**
- 自动识别常见中英文表头（姓名、性别、出生日期、入职日期、部门、职位、是否干部、学历、电话、邮箱、合同到期日、备注）
- 导入前提供**数据预览**与字段识别提示，确认无误后批量入库
- 老版 `.ppt` 需本机安装 LibreOffice 自动转换，或先另存为 `.pptx`

### 3. 自动统计（实时更新）
- 员工总数、男性/女性数量、干部数量、平均年龄、平均工龄、部门数量
- 合同即将到期数、合同已过期数
- 性别分布（环形图）、各部门员工数、年龄结构、工龄结构、学历构成（条形图）

### 4. 劳动合同到期提醒
- 新增"合同到期日"字段（编辑对话框中可勾选"未填写"）
- 提前 **30 天**提醒：已过期 / 即将到期分级显示
- 独立的"合同到期提醒"页面，卡片式列出姓名、部门、到期日、剩余天数与状态
- 仪表盘同步显示提醒概览与统计卡片（仅统计在职员工）

### 5. 已离职员工管理（新）
- 花名册表格新增"**状态**"列（在职显示绿色），并新增"**办理离职**"按钮
- 办理离职时选择离职日期，员工自动移入"**已离职员工**"列表
- 已离职列表展示姓名、性别、部门、职位、离职日期，支持"**恢复在职**"
- 编辑对话框也可直接勾选"已离职"并填写离职日期
- 仪表盘新增"已离职员工"统计卡；统计口径只含在职员工（离职人员不参与性别/年龄/工龄/合同等统计）

## 字段说明

姓名、性别、出生日期、入职日期、部门、职位、是否干部、学历、电话、邮箱、**合同到期日**、**是否已离职**、**离职日期**、备注。
年龄由出生日期自动计算，工龄由入职日期自动计算。旧数据库会自动迁移新增列，历史数据不丢失。

## 运行方式

本项目为**多文件源码包**（非单一安装程序），依赖通过安装脚本自动拉取。

**Windows（推荐）**：
1. 先安装 Python 3.9+（安装时勾选 "Add Python to PATH"）
2. 双击 **`installer.bat`** 自动创建虚拟环境并安装依赖（约几分钟，只需一次）
3. 之后双击 **`启动软件.bat`** 即可运行（若未安装环境会自动调用 installer）
> 若双击中文文件名的 bat 出现乱码，属正常显示差异，不影响功能；也可在 cmd 中运行 ` installer.bat`。

**macOS / Linux**：
```bash
./启动软件.sh
# 或
python3.11 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

> zip 包中**不含** `.venv`（Linux 构建、跨平台不可用且体积大），请在目标机器用上述脚本自动创建。

## 项目结构

| 文件 | 说明 |
|------|------|
| `main.py` | 主窗口、统计看板、花名册、已离职列表、合同提醒页、各类对话框 |
| `models.py` | 员工数据模型与 SQLite 封装（含旧库自动迁移） |
| `stats.py` | 统计与合同到期计算逻辑 |
| `import_utils.py` | 多格式文件解析与智能表头映射 |
| `glass_widgets.py` | Liquid Glass 风格 UI 组件库 |
| `installer.bat` | Windows 一键安装依赖脚本（创建 venv + pip install） |
| `启动软件.bat` | Windows 一键启动脚本（缺环境时自动安装） |
| `启动软件.sh` | macOS / Linux 一键启动脚本 |
| `requirements.txt` | Python 依赖清单 |

## 使用提示

- 双击表格行可直接编辑员工信息
- 左上角 macOS 交通灯：**红点关闭**、**黄点最小化**、**绿点全屏/还原**；拖动顶部标题栏可移动窗口，双击标题栏切换全屏
- "办理离职"后员工移入已离职列表，在列表中选中后点"恢复在职"可撤销
- 数据保存在 `employees.db`（SQLite），首次运行自动创建
- 导入支持中文表头，如列名特殊会在预览时提示"未识别列（已忽略）"
